\begin{enumerate}

\item Model-based Systems Engineering is the formalized application of modelling to support system requirements, design, analysis, verification, and validation activities beginning in the conceptual design phase and continuing throughout development and later life cycle phases.[INCOSE2007]

\item The architecture of a system denotes the fundamental concepts or properties of a system in its environment embodied in its elements, relationships, and in the principles of its design and evolution. [ISO-42010]

\item The architecture of a system can be understood as a set of structured
architectural entities and of their relationships, such as functions, function flows, interfaces, resource flow items,
information/data elements, physical components, containers, nodes, links, communication resources, etc. These architectural
entities may possess characteristics such as dimensions, environmental resilience, availability, robustness, execution
efficiency, mission effectiveness, etc.[ISO-15288]

\item The functional architecture describes the functional concepts and principles of the system regardless of the
structures they implement [Weilkiens2014]. A system is modelled by a set of functions that describe
transformations of inputs into outputs and fulfill the system purpose in their entirety. These functions can be
assigned to system elements.

\item behavior model the system behavior is in the foreground, which is described e.g. over different
application scenarios and the desired system behavior there. Here aspects such as system states and
transitions between the states or sequential or parallel execution are in the focus.

\item A temporal model describes the temporal behavior of the system on different levels from strategic decisions to
the operational level.

\item A structural model divides the system into elements and describes the interfaces between these elements and
to external units. “Such a model enables consolidating or identifying physical interfaces between system
elements in a level of the system hierarchy and between levels of the system hierarchy, as well as those with
external entities to the concerned system (in its environment/context).”

\item the mass model geometries, masses, positions, orientations and motion behavior are assigned to the
system elements.

\item The layout model concentrates on the position and orientation of the system elements in space.

\item A network model describes how resources such as masses, energy, data and people “flow” from one system
element to another.

\end{enumerate}
